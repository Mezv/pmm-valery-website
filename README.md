# valerymezencev.com

Personal landing page for Valery Mezencev — Senior Product Marketing Manager and GTM strategist.

## Stack

Plain HTML/CSS/JS — no build step, no dependencies. Deployed as a static site.

## Structure

```
index.html    # Single-page site
profile.jpg   # Hero avatar
favicon.png   # Browser tab icon (32×32, generated from profile.jpg)
```

## Local development

Open `index.html` directly in a browser — no server needed.

## Deployment

Push to `main`. The site is hosted at [valerymezencev.com](https://valerymezencev.com).
